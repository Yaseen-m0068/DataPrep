# DataPrep

### Explainable Automated Preprocessing Assistant

DataPrep is an interactive data preprocessing tool that helps users understand, clean, transform, and prepare structured datasets for data analysis and machine learning.

Instead of automatically modifying a dataset, DataPrep analyzes the data, identifies potential preprocessing issues, presents suitable preprocessing options, explains the available choices, and allows the user to build a customized preprocessing pipeline.

## Current Status

🚧 Project under active development.

## Planned Features

- Dataset ingestion
- Automatic dataset profiling
- Data type detection
- Missing value analysis
- Duplicate detection
- Categorical preprocessing
- Numerical preprocessing
- Outlier detection and treatment
- Date and text preprocessing
- Preprocessing recommendations
- Interactive preprocessing configuration
- Before/after data validation
- Transformation history
- Reproducible preprocessing pipeline
- Preprocessing code export
